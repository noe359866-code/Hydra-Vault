☁️ Integración con Cloudflare Worker

En tu Worker de Cloudflare, simplemente realiza un fetch a esta API: 

const res = await fetch(\`https://tu-api.vercel.app/api/vault?id=\${stremioId}\`);
const data = await res.json();
if (data.success && data.streams) {
  return data.streams; // Streams ya formateados
}

La API resuelve consultas en milisegundos y devuelve las cabeceras CORS universales habilitadas.
